# Product photos

The demo hotlinks product photography from Unsplash (`images.unsplash.com`), as the Unsplash API guidelines ask, so this folder is empty in the demo.

For a real store, put the client's own photos here (e.g. `pulse-anc-headphones-1.jpg`, `-2.jpg`, `-3.jpg`, square, 1200×1200, ~80% JPEG/WebP) and change the `img()` helper in `js/script.js` to return `images/products/<id>-<view>.jpg`. See README → "Replacing assets".
